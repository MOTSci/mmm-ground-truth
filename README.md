# MMM Ground Truth

> **Synthetic weekly MMM data where the true answer is known, so you can check whether your model recovers it.**
>
> Purpose: Synthetic weekly MMM data with known ground truth, endogenous spend and a Search-clicks bias. Test your model against the answer.

*Key chart: coming soon.*

## Why this matters

With real marketing data, nobody knows the true effect of each channel, so a model's output cannot be checked against the truth. This dataset is built with the true effects set in advance, so you can see how close an MMM gets to them. It also includes two common traps: spend that reacts to demand (endogenous spend) and a Search-clicks bias. That lets you test whether a model is fooled by them.

## What I did

1. **Data:** Synthetic weekly marketing data generated by the code in this repository. Every number is simulated. Period and channel details: coming soon.
2. **Method:** A simulation that sets each channel's true effect first, then generates spend and sales from it. Spend is endogenous (it responds to expected demand, the way budgets often do in practice), and Search clicks carry a built-in bias. Full specification: coming soon.
3. **Validation:** Parameter recovery (fit a model to the simulated data and compare its estimates with the true values used to generate it). Results: coming soon.

## Reproduce it

```bash
git clone https://github.com/MOTSci/mmm-ground-truth.git
cd mmm-ground-truth
uv sync                      # installs Python 3.13 and the exact dependencies
uv run pre-commit install    # blocks accidental data commits
uv run jupyter lab           # open notebooks/ and run in order
```

Data: this repository contains only synthetic data in `data/sample/`. Details on how it is generated: coming soon.

## Project structure

```
├── configs/        <- Simulation settings (true effects, spend rules, bias)
├── data/
│   ├── raw/        <- Original, immutable data (never edited)
│   ├── external/   <- Third-party data
│   ├── interim/    <- Intermediate transformations
│   └── processed/  <- Final datasets used for analysis
├── docs/           <- Decision log, assumptions, brief
├── notebooks/      <- Numbered, in order: 01-eda, 02-analysis, ...
├── reports/figures/<- Charts for the report and README
├── src/mmm_ground_truth/ <- Reusable code
└── tests/          <- Tests for src code
```
