# MMM Ground Truth

> **Synthetic weekly MMM data where the true answer is known, so you can check whether your model recovers it.**
>
> Purpose: Synthetic weekly MMM data with known ground truth, endogenous spend and a Search-clicks bias. Test your model against the answer.
>
> **Every number here is simulated.** No real company, customer or campaign is behind it.

## Why this matters

With real marketing data, nobody knows the true effect of each channel, so a model's output cannot be checked against the truth. This dataset is built with the true effects set in advance, so you can see how close an MMM gets to them. It also includes two common traps: spend that reacts to demand (endogenous spend) and a Search-clicks bias. That lets you test whether a model is fooled by them.

## What I did

1. **Data:** Synthetic weekly data generated by the code in this repository: 156 weeks from 2022-01-03, five channels (TV, OOH, Meta, YouTube/display, Search), 18 observed columns, money in thousand USD. The default dataset uses config v1.0.0 and seed 2026. The truth is saved separately in `ground_truth.json`.
2. **Method:** A simulation that sets each channel's true effect first (adstock carryover and Hill saturation), then generates spend and sales from it. Spend is endogenous: it follows the season, ramps up before promotions, chases recent sales, and for Search tracks a hidden demand shock. Search clicks mix incremental clicks with clicks from existing demand. Full specification: [`docs/simulator_reference.md`](docs/simulator_reference.md). Every config key: [`docs/config_guide.md`](docs/config_guide.md).
3. **Validation:** Parameter recovery (fit a model to the simulated data and compare its estimates with the true values used to generate it). The simulator itself is checked by a built-in self-check (row count, no missing values, no hidden columns leaked into the CSV) and by reproducibility: the same config and seed give byte-identical files on numpy 2.1.3 / pandas 2.2.3, numpy 2.5.3 / pandas 3.0.5 and numpy 2.5.4 / pandas 3.1.1. ## Key findings

Model results: coming soon. What the default dataset (seed 2026) contains by construction:

- All media together account for **23.6%** of sales (realized, from `ground_truth.json`).
- **39.4%** of observed Search clicks are not incremental, so a model fit on clicks is expected to be biased by construction.
- Search spend correlates with the hidden demand shock at about **0.24**. For the other channels the correlation is about zero. Search is where the hidden confounding matters.
- Realized average ROAS differs by channel (about 1.5 for YouTube/display to about 2.9 for Search), so a model can be scored channel by channel.

These describe the simulation, not real markets.

## What this analysis can and cannot claim

- **Can claim:** how close a model's *estimated contribution* is to the known simulated contribution, on this dataset and under this simulated mechanism.
- **Cannot claim:** that results on this synthetic data carry over to any real brand's marketing. The dataset tests methods; it does not measure real-world effects. One seed is one draw, so a single run cannot separate a model's bias from bad luck.
- **Assumptions:** see [`docs/decisions.md`](docs/decisions.md) and the list of limitations in [`docs/simulator_reference.md`](docs/simulator_reference.md#limitations-read-before-drawing-conclusions).

## Reproduce it

**Requirements:** [uv](https://docs.astral.sh/uv/) and git. uv installs Python 3.13 and the pinned packages.

**1. Get the code and install**

```bash
git clone https://github.com/MOTSci/mmm-ground-truth.git
cd mmm-ground-truth
uv sync
```

**2. Generate the dataset** (about 5 seconds; writes `synthetic_mmm_data.csv` and `ground_truth.json`)

```bash
uv run python src/simulate_mmm.py --config configs/config_v1.yaml --outdir data
```

**3. Check it worked.** The terminal prints a summary table that starts with `SYNTHETIC data | config v1.0.0 | seed 2026`. The same config and seed always give identical files.

**4. Optional: the notebook** (charts and checks)

```bash
uv run --with jupyterlab jupyter lab    # open notebooks/01_generate_dataset.ipynb
```

**Options:** `--seed N` changes the random draw. `--no-confounding` switches off the hidden confounding, so you can test your model on the easy version first. All options and the Python API: [`docs/simulator_reference.md`](docs/simulator_reference.md).

**Contributors only:** run `uv run pre-commit install` once. It blocks accidental data commits.

## Limitations and next steps

- Limitations: parameters are illustrative, not calibrated to any real business; seasonality is easy to model; effects are additive (no synergies); data is clean (no outliers or measurement error); one market. Full list: [`docs/simulator_reference.md`](docs/simulator_reference.md#limitations-read-before-drawing-conclusions).
- Next steps: fit MMMs to this dataset and score them against the truth; repeat over many seeds to separate bias from luck; add the key chart.
