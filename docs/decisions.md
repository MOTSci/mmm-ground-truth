# Decision log

Record every choice that changes the result: data cleaning, priors, model form, exclusions. Future you, and any client, will ask "why did we do that?"

Newest first. One entry per decision.

## Template (copy for each decision)

### YYYY-MM-DD: [short title]

- **Decision:** what you chose
- **Why:** the reason, and the evidence behind it
- **Alternatives considered:** what you did not choose, and why
- **Risk if wrong:** what would change in the results
- **Status:** proposed / accepted / revisited
